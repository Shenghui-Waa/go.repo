`go.repo` is a collection of utilities and data structures implemented with
Go 1.25. Its API contracts are derived from the Java 25 Collections Framework
while retaining idiomatic Go APIs.

The current version provides the `Comparable[T any]` comparison contract and
can be used together with [**GoDS**](https://github.com/emirpasic/gods.git).

## Installation

GoDS is used as a dependency:

```text
github.com/emirpasic/gods v1.18.1
```

The current version of this project is `v0.1.1`. The following module paths
are equivalent:

- `github.com/Shenghui-Waa/go.repo` *(recommended)*
- `gitee.com/Shenghui-Waa/go.repo`
