# go.repo

---

[**English ↗**](./README.md)

---

`go.repo` 是一个基于 Go 1.25 实现的相关工具和数据结构库。
其接口契约派生自 Java 25 Collections Framework，同时保留符合 Go 语言习惯的 API。

当前版本仅提供 `Comparable[T any]` 比较器，并可以配合 [**GoDS**](https://github.com/emirpasic/gods.git) 使用

## 获取

优先使用 GoDS `github.com/emirpasic/gods`，版本号 `v1.18.1`

本项目当前可用版本号为 `v0.1.1`，提供两个端点（这两个端点是等价的）：

- `github.com/Shenghui-Waa/go.repo` *（建议）*
- `gitee.com/Shenghui-Waa/go.repo`
